## 🛠️ 4. Panduan Penggunaan & Konsumsi Data untuk Anggota Tim

### A. Mengakses Metadata via Endpoint Internal MAPID:
Semua dataset di atas dapat dicek skema atributnya (kolom-kolom datanya) menggunakan API:
```bash
# Format Request
curl "https://server.mapid.io/moneys_bun/get_data_premium_by_category_id?search_params={NAMA_DATASET}"
```

Contoh response JSON mencakup array `fields` yang merinci:
- Koordinat (`LONGITUDE`, `LATITUDE`)
- Wilayah administrasi (`KECAMATAN`, `DESA`, `KABKOT`)
- Nilai kuantitatif (indeks demografi, radiansi cahaya malam, nilai pengeluaran, dll.)

### B. Cara Mengunduh File Spasial Penuh (GeoJSON / SHP):
1. **Melalui Dashboard GEO MAPID**: Login ke [geo.mapid.io](https://geo.mapid.io), cari ID Layer di atas melalui Data Catalog / Project Editor, lalu tambahkan ke Project dan klik **Export Data**.
2. **Melalui Script Backend TransitERA**: Jika Anda memiliki cookie sesi login MAPID, kita bisa memasukkan cookie tersebut ke file `.env` (`MAPID_COOKIE=...`) agar script otomatis mengunduh dan menyinkronkan seluruh poligon/titik ke database PostGIS lokal kita.
